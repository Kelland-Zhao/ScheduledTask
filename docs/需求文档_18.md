# 需求文档 — 18 号项目：质量巡场未解决问题每日提醒

> 版本：V20260606.1 | 状态：已确认

---

## 1. 项目背景

注塑车间每月进行质量巡场（TB1/TB2），记录机台质量问题及跟进情况。巡场记录表中有多个 sheet（每月一份），需要每日自动扫描所有当年 sheet，找出**未解决**的问题，汇总发送给 S&C 团队跟进。

---

## 2. 核心功能

### 2.1 数据读取

| 数据源 | 表 ID | Sheet 范围 | 过滤条件 |
|---|---|---|---|
| 质量巡场记录 | `1O-cwRTfW7jB-TSAeDDNvi_LyEM-Dhsi_Y2AqIwbku4c` | 所有 sheet，**排除**「巡场模板」 | 仅扫描 **2026 年**的 sheet |

### 2.2 列结构（所有数据 sheet 统一）

| 列 | 字段 | 说明 |
|---|---|---|
| A | NO. | 序号 |
| B | 机台号 | 机台编号 |
| C | 品种 | 产品品种 |
| D | 问题描述 | 问题详细描述 |
| E | 优先级 | A/B/C |
| F | 跟进措施 | 处理措施 |
| G | 预计完成日期 | 计划完成日期 |
| H | 责任人 | 负责跟进的人 |
| I | 当前状态 | Done / Ongoing / 转SDM / 空 |

- 数据从第 4 行开始，第 3 行为表头，第 1 行为日期/参与人员信息

### 2.3 未解决判定

| 状态 | 判定 |
|---|---|
| `Done` | ✅ 已解决，**排除** |
| `Ongoing` | ❌ 未解决，**包含** |
| `转SDM` | ❌ 未解决，**包含** |
| 空值 | ❌ 未解决，**包含**（问题已记录但未更新状态） |

- 匹配时忽略前后空格，大小写不敏感
- NO. 为空的行（无内容行）跳过不处理

### 2.4 输出

**Gmail 邮件（一封）：**
- 收件人：权限表 `userID` 中 `O列(工序)=INJ` 且 `P列(职位)=S&C` 的人（取 J列 GMail）
- 邮件标题：`[质量巡场] 未解决问题汇总 YYYY-MM-DD`
- 邮件正文：按 **Sheet 名** 分组展示，每个 Sheet 一个 HTML 表格区块
- 表格列：NO. | 机台号 | 品种 | 问题描述 | 优先级 | 跟进措施 | 预计完成日期 | 责任人 | 当前状态
- 如果所有 sheet 均无未解决问题，邮件正文显示「无未解决问题」
- 发件人名称：`Quality Tour Alert`

无需额外权限控制。收件人由 `userID` 表动态过滤（O=INJ + P=S&C）。

---

## 8. 边界条件

| 场景 | 处理 |
|---|---|
| 巡场记录表无 2026 年 sheet | 跳过，Log 记录 |
| 某 sheet 无数据行（仅表头） | 跳过该 sheet，不报错 |
| 某 sheet 所有问题均已 Done | 该 sheet 在邮件中不出现 |
| 所有 sheet 均无未解决问题 | 邮件正文显示「无未解决问题」 |
| 权限表无匹配收件人 | 跳过邮件发送，Log 记录 |
| NO. 列为空的行 | 视为无效行，跳过 |
| 状态列含空格（如 `转SDM `） | trim 后再匹配 |
| 新增 sheet（未来月份） | 自动纳入扫描（只要 sheet 名含 `2026`） |

---

## 9. 验收标准

1. 每天 08:40 自动执行，发送未解决问题汇总邮件
2. 专项菜单可手动触发
3. 邮件按 Sheet 分组正确展示所有未解决问题
4. `Done` 状态的问题不出现在邮件中
5. `Ongoing`、`转SDM`、空状态的问题正确列出
6. 仅扫描 2026 年 sheet，不包含「巡场模板」
7. Log 中正确记录每次执行状态
